# PC Sentinel 0.3.2 — частная некоммерческая установка

Запустите PCSentinel-0.3.2-Setup.exe и подтвердите UAC. Файлы устанавливаются только в Program Files\PC Sentinel, folder-сборкой: нативные .NET/WPF DLL находятся рядом с программой, а не извлекаются повышенным процессом в пользовательский TEMP.

На поддерживаемом Intel/AMD без PawnIO установщик предлагает отдельную галочку установки официального подписанного PawnIO 2.2.0. Она выключена по умолчанию. Для температур CPU и Intel GT отметьте её и оставьте включённой службу датчиков. Перед запуском драйвера проверяется закреплённый SHA256.

Служба PCSentinelSensors работает от LocalSystem и выдаёт только температуры через локальный канал с правами только на чтение. Обычная программа не запускает повышенный EXE и не запрашивает UAC. Источник службы и права на его файлы проверяются. Сетевое подключение к каналу запрещено; API управления аппаратурой клиентам не предоставляется. Одновременно обслуживается один экземпляр интерфейса на ПК.

В Настройки → Температуры можно подключить или отключить получение показаний службы. CPU/GPU могут быть недоступны на другом оборудовании или без драйвера. AMD: поддерживается аппаратная контрольная температура Tctl семейств 17h–1Ah; это не обещание показаний Tdie. Проверка AMD на физическом AMD-ПК ещё требуется.

Дистрибутив пока НЕ подписан Authenticode: сертификата у владельца проекта нет. Windows покажет «неизвестный издатель» при запуске установщика. Подпись самого PawnIO от этого не зависит. Сверяйте SHA256 установщика с файлом .sha256, полученным от автора вместе с дистрибутивом. Самоподписанный сертификат не устанавливается.

При обновлении программа получает штатный запрос выхода; старую переносную версию без такой функции нужно завершить через «Выход» в трее. Служба останавливается перед заменой файлов. Старый каталог временно переносится в Program Files\PC Sentinel.previous-...; после успешного обновления защищённая резервная копия удаляется. Если её права не позволяют подтвердить безопасность удаления, она сохраняется и путь пишется в журнал установки.

Удаление: Параметры Windows → Приложения → PC Sentinel. Служба и относящийся к установленному EXE автозапуск удаляются. История и настройки в %LOCALAPPDATA%\PCSentinel сохраняются. PawnIO остаётся, поскольку им могут пользоваться другие программы; при необходимости удаляется отдельно через Приложения Windows.

Переносной EXE работает без привилегированного помощника и не подходит для установки службы. SDK, исходники, тестовые БД, скриншоты и результаты тестов в установщик не включаются.
