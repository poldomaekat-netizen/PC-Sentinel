## Проверки и ограничения

Существующие результаты: 179 успешных тестов. Установка/запуск на сторонних ПК без среды разработки проверены владельцем. Подробнее — [TESTING.md](TESTING.md).

Authenticode-подписи пока нет; Windows может показать неизвестного издателя. Владелец работает над приобретением сертификата. Доступность датчиков зависит от оборудования; физическая AMD-проверка ещё требуется. Программа не заменяет антивирус и не гарантирует защиту VPN.

История хранится локально. Проверка внешнего IP включена по умолчанию и обращается к внешним сервисам; её можно отключить в настройках.
