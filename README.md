# PC Sentinel

**Ресурсы, процессы, сеть и температура компьютера — в одном окне.**

PC Sentinel — приложение для Windows с интерфейсом WPF, настольным виджетом и локальной историей измерений. Помогает наблюдать за состоянием ПК и разбираться в изменениях нагрузки.

[Скачать установщик](../../releases/latest) · [Установка](docs/INSTALL.md) · [Сборка](docs/BUILD-INSTALLER.md) · [Проверки](docs/TESTING.md)

## Возможности

- Мониторинг CPU, RAM, дисков, процессов и сетевой активности.
- Температуры CPU/GPU/накопителей, если их предоставляют оборудование и драйверы.
- Настольный виджет с настройкой расположения и прозрачности.
- История измерений, диагностические события и экспорт данных.
- Проверки внешнего IP и состояния VPN с отображением неопределённости.
- Отдельная служба температур: интерфейс работает без повторного запроса UAC.

## Скачать и установить

В [Releases](../../releases) выберите **PCSentinel-0.3.2-Setup.exe**. Версия приложения — **0.3.2**, версия файла — **0.3.2.1**, Installer build 1.

Требуется Windows x64; установщик допускает Windows 10 1809 и новее. Приложение включает необходимые .NET runtime: отдельно устанавливать .NET SDK, библиотеки или среду разработки не нужно. Установка и запуск на сторонних ПК без среды разработки проверены владельцем проекта.

1. Скачайте Setup и файл .sha256 из одного выпуска.
2. При желании проверьте SHA256 командой Get-FileHash в PowerShell.
3. Запустите установщик и подтвердите UAC. Программа устанавливается в Program Files.

Для аппаратных температур установщик предлагает **необязательную установку официального PawnIO 2.2.0**. Галочка установки драйвера по умолчанию снята. Доступность датчиков зависит от конкретного ПК. При удалении PC Sentinel история и настройки сохраняются; общий драйвер PawnIO удаляется отдельно при необходимости.

В этом выпуске распространяется установщик. Переносная сборка не предлагается для скачивания.

## Подпись и ограничения

Установщик пока не имеет Authenticode-подписи: при установке Windows может показать «неизвестный издатель». Владелец проекта работает над приобретением сертификата. SHA256 позволяет сверить файл с опубликованной контрольной суммой.

PC Sentinel не заменяет антивирус. Наличие процесса или события само по себе не означает угрозу. VPN-проверки не гарантируют защиту всех приложений и всех сетевых направлений. AMD Tctl обозначается как контрольная температура, а не Tdie; проверка на физическом AMD-оборудовании ещё требуется.

## Данные и внешние запросы

История и настройки хранятся локально в %LOCALAPPDATA%/PCSentinel. Проверка внешнего IP включена по умолчанию и обращается к ipify.org и icanhazip.com: эти сервисы видят исходящий IP. Её можно отключить в настройках. Проверки контрольных сайтов включаются отдельно; посещаемые сервисы также видят исходящий IP. Диагностика может содержать имена процессов, пути и адреса; перед публикацией экспортов проверьте их содержимое.
